# Claude Forge

A personal collection of handy plugins for Claude Code.

## Installation

```bash
# Add the marketplace
/plugin marketplace add illia1f/claude-forge

# Install a plugin
/plugin install <plugin-name>@claude-forge
```

## Plugins

### [ideation](./plugins/ideation)

Multi-agent codebase ideation framework. Analyzes projects for improvements across security, UI/UX, performance, code quality, documentation, and code patterns.

### [git-commands](./plugins/git-commands)

Git workflow skills: create commits (project rules or Conventional Commits), generate PR descriptions, and clean up gone branches and their worktrees.
